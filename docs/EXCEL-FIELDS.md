# Registro de pendientes según el Excel de todas las marcas

El archivo «PENDIENTES - TODAS LAS MARCAS - FUNKA.xlsx» se utiliza como referencia de columnas. No se importaron sus filas.

| Excel | Aplicación |
| --- | --- |
| Marca | Marca y equipo del pedido |
| Encargado | Responsable registrado con acceso al equipo y marca |
| Asignada el | Fecha de asignación editable |
| Deadline | Fecha y hora límite en Lima |
| Prioridad | Baja, Normal, Alta o Urgente |
| Tiempo aprox. / Tiempo de pieza | Tiempo estimado, en minutos |
| Campaña | Nombre de campaña editable |
| Tipo / Tipo de pedido | Catálogo de tipos de Administración |
| Detalle pedido | Título y brief |
| Estado | Columnas del tablero y acciones de estado |
| Enlace de entrega | Entregas con historial |
| RRSS | Red social, independiente del canal WP/SIS |
| Día de posteo | Fecha de publicación, independiente del deadline |

Los nuevos campos están en Nuevo pedido y en los detalles de cada pedido. Son opcionales y compatibles con los pedidos anteriores. La exportación CSV también los incluye. Sus etiquetas se pueden editar en Administración → Textos de la web. Un pedido nuevo con responsable comienza como Pendiente; sin responsable comienza Por asignar. Los cambios conservan el control de versiones y el historial.

Antes de importar datos hay que resolver las discrepancias del archivo: diversas hojas, incluidas CAT, UMBRO y CONVERSE, contienen filas de NB repetidas. Tampoco se debe usar LISTO como prioridad: es un indicador que requiere revisión, separado del estado. La asignación debe enlazarse a usuarios reales; un nombre en el Excel no otorga acceso ni identifica por sí solo una cuenta.
